# 老闆痛點句庫

好的文案從老闆每天遇到的狀況開始，而不是從你會什麼技術開始。
每句都是**老闆自己會講出口的話**，後面標出背後對應的服務，方便你從技術能力反推文案。

寫標題、服務介紹、「你是不是也遇到這些問題」區塊時，從這裡挑 3–5 句最貼近對象的用。
可以改寫成對方的行業用語，但保持口語，不要加回技術詞。

## 標準範本（品質基準）

這幾句是好文案的標準。新寫的痛點句要跟它們一樣具體、一樣口語：

- 「同一筆資料要在三個地方各輸入一次」
- 「Excel 已經撐不住」
- 「你配合工具／系統配合你」
- 「跟 AI 說一句話，網站自己帶客人找到商品」

共同點：講得出畫面、有具體的物件（Excel、資料、商品），沒有任何技術詞。

## 1. 客人詢問與接待

| 老闆會說的話 | 背後的服務 |
|---|---|
| 半夜客人傳訊息問，早上回的時候人已經跑了 | AI 客服、24 小時自動回覆 |
| 每天都在回一樣的問題：多少錢、在哪裡、有沒有貨 | 常見問題自動回覆 |
| 網站有人看，但都沒人來問 | 會導購的 AI 網站、轉換率改善 |
| 客人問到一半就不回了 | 主動追蹤、自動提醒 |
| 店員回答的內容每個人都不一樣 | AI 知識庫，統一回答 |
| LINE 訊息太多，重要的被洗掉 | LINE 訊息分類、自動標記 |
| 不知道哪個客人是真的要買，哪個只是問問 | 客人篩選、詢價分級 |
| 新人來要教很久，才答得出客人的問題 | 內部 AI 助手 |

## 2. 接單、預約與收款

| 老闆會說的話 | 背後的服務 |
|---|---|
| 客人用 LINE 下單，我再手抄到 Excel | 線上下單、訂單自動彙整 |
| 預約靠電話和紙本，常常重複排到同一個時段 | 線上預約系統 |
| 客人預約了沒來，也沒先講 | 預約前自動提醒 |
| 對帳對到半夜，還是有幾筆對不起來 | 金流串接、自動對帳 |
| 開發票、寄出貨單都要手動 | 電子發票、物流串接 |
| 報價單每次都從頭做 | 報價自動產生 |
| 訂金有沒有收到要一筆一筆查 | 付款狀態自動通知 |

## 3. 資料與重複工作

| 老闆會說的話 | 背後的服務 |
|---|---|
| 同一筆資料要在三個地方各輸入一次 | 系統串接、資料同步 |
| Excel 已經撐不住，檔案越來越大、越來越慢 | 客製管理系統 |
| 檔案到處傳，不知道哪一份才是最新的 | 單一資料來源、雲端系統 |
| 每天花一兩個小時在複製貼上 | 自動化流程 |
| 客人的資料散在 LINE、Excel、紙本，要找很難 | 客人資料管理（CRM） |
| 只有某個員工知道怎麼弄，他請假就沒人會 | 流程系統化 |
| 單據、名片要一張一張打進電腦 | 拍照辨識（OCR） |
| 你配合工具，而不是工具配合你 | 客製化系統 |

## 4. 庫存、排班與內部管理

| 老闆會說的話 | 背後的服務 |
|---|---|
| 網路和門市的庫存對不起來，常常賣出沒貨的東西 | 庫存同步 |
| 排班表每個月都要喬很久 | 排班系統 |
| 員工打卡、請假還在用紙本 | 內部管理系統 |
| 分店的狀況我要一家一家打電話問 | 多店管理後台 |
| 叫貨靠感覺，常常太多或不夠 | 進貨建議、銷售預測 |
| 現成的軟體功能很多，但就是少了我要的那一個 | 客製化開發 |
| 現成軟體每個月租金越來越貴 | 自建系統、降低月費 |

## 5. 數字與決策

| 老闆會說的話 | 背後的服務 |
|---|---|
| 月底才知道這個月賺還是賠 | 營運儀表板 |
| 做報表要花半天，看的時候已經過時了 | 報表自動化 |
| 不知道哪個商品賺錢、哪個在虧 | 銷售分析 |
| 廣告錢花下去，不知道有沒有帶來客人 | 廣告成效追蹤 |
| 數字一大堆，看不出重點 | 重點數字整理、圖表化 |

## 6. 網站與曝光

| 老闆會說的話 | 背後的服務 |
|---|---|
| 網站做好就放著，像一張名片 | 會接客的網站 |
| 在 Google 搜不到我們 | SEO |
| 用手機看網站，字很小、按鈕按不到 | 手機版網站 |
| 想改一張照片都要找人改 | 可自己編輯的後台 |
| 網站很慢，客人等不及 | 網站速度改善 |
| 網站很久沒更新，看起來像倒了 | 網站改版 |

## 7. 對 AI 的期待與疑慮

老闆對 AI 常同時有期待和害怕，文案要兩邊都接住。

| 老闆會說的話 | 怎麼回應 |
|---|---|
| 大家都在講 AI，但我不知道能拿來幹嘛 | 「告訴我你每天最煩的事，我告訴你 AI 能不能做」 |
| 我有用 ChatGPT，但只拿來寫文案 | 「AI 能做的不只寫字，還能直接幫你回客人、整理訂單」 |
| AI 會不會亂回答客人？ | 「AI 只照你的資料回答，不確定的會轉給你」 |
| 我的資料放上去安全嗎？ | 說清楚資料放哪、誰看得到 |
| 會不會很貴？ | 「先做一個簡單版試試，有效再加」 |
| 我不懂技術，會不會很難用？ | 「你只要會用 LINE 就會用」 |
| 做完之後壞了怎麼辦？ | 講清楚上線後的照顧方式 |

## 8. 跟廠商合作的不安

這些是老闆找技術廠商時最怕的事，放在服務頁或聯絡頁能降低他的戒心。

| 老闆擔心的事 | 文案可以怎麼回應 |
|---|---|
| 工程師講話我聽不懂 | 「你講生意，我負責翻譯成技術」 |
| 做出來跟我想的不一樣 | 「每兩週給你看進度，隨時可以調整」 |
| 報價後一直追加費用 | 「先講清楚做什麼、不做什麼，報價就是總價」 |
| 做完人就找不到了 | 「上線後我還在，出問題找得到人」 |
| 被綁死，以後換不了廠商 | 「程式和資料都是你的」 |
| 花了錢卻沒人用 | 「先從一個最痛的地方開始，效果看得到再擴大」 |
