# 用語對照表

每條三欄：**工程用語 → 老闆聽得懂的說法 → 什麼時候可以保留原詞**。
「可保留」是空的，就代表寫給老闆看的文字裡一律換掉。

同一個詞常有好幾種說法，請依上下文挑一個，**挑定後全站統一**。

## 1. AI 相關

| 工程用語 | 老闆聽得懂的說法 | 可保留原詞的情況 |
|---|---|---|
| AI | AI（保留） | 「AI」對老闆有吸引力，直接用；要說清楚 AI 幫他做了什麼 |
| AI Agent | AI 助手、AI 店員、會自己動手做事的 AI | 第一次出現可以寫「AI 助手（業界叫 AI Agent）」 |
| Chatbot／聊天機器人 | 自動回覆客人的小幫手、24 小時線上客服 | 「聊天機器人」老闆聽得懂，但容易聯想到很笨的罐頭回覆，最好補一句「會看懂問題再回答」 |
| LLM／大型語言模型 | 像 ChatGPT 那樣的 AI | |
| GPT／Claude／Gemini | ChatGPT 那一類的 AI | 老闆指名要某一家時才講品牌 |
| Prompt／提示詞 | 給 AI 的工作說明、教 AI 怎麼回答 | |
| Prompt Engineering | 把 AI 調教到回答得像你的員工 | |
| Fine-tune／微調 | 用你公司的資料再訓練，讓 AI 更懂你的生意 | |
| RAG／檢索增強生成 | 讓 AI 先查你的資料再回答，不會亂掰 | |
| 知識庫 | 你的商品資料、常見問題整理成 AI 查得到的資料 | 「知識庫」老闆大致聽得懂，可以保留 |
| 向量資料庫／Embedding | （不提，併入「讓 AI 查得到你的資料」） | |
| 幻覺（Hallucination） | AI 亂講、編出不存在的答案 | |
| 多模態 | 看得懂照片、聽得懂語音的 AI | |
| OCR | 拍照就能把單據上的字讀進系統 | |
| 語音辨識／STT | 講話自動變成文字 | |
| TTS／語音合成 | 文字自動念出來 | |
| 生成式 AI | 會寫文案、做圖的 AI | |
| AI 自動化流程 | 把重複的雜事交給 AI 做 | |
| AI 工作流程落地 | 把 AI 真的用進每天的工作，不只拿來潤飾文字 | |
| AI 導入 | 幫公司把 AI 用起來 | |
| AI 應用 | AI 能幫你做的事 | |
| Token／用量計費 | AI 的使用費，用多少算多少 | 報價單要寫清楚「每月大約多少錢」，不要只寫 token 單價 |
| 模型 | AI 本身 | |
| 意圖辨識 | 看懂客人想問什麼 | |
| 情感分析 | 看出客人是不是不開心 | |
| 推薦系統 | 依照客人喜好自動推薦商品 | |
| AI 沈浸式網站 | 會導購的 AI 網站、會帶客人逛的網站 | 「沈浸式」是設計圈用語，老闆看不出好處 |
| MCP／Tool Use／Function Calling | 讓 AI 能直接幫你查訂單、改預約（不只是聊天） | |

## 2. 串接與自動化

| 工程用語 | 老闆聽得懂的說法 | 可保留原詞的情況 |
|---|---|---|
| API | 讓兩套系統自動交換資料的接口 | 對方廠商說「有沒有 API」時，告訴老闆「這是在問系統能不能接」 |
| API 串接／系統串接／跨系統串接 | 讓你現在用的工具互相同步，資料只要輸入一次 | |
| 串接 AI 與資料 | 讓 AI 看得到你的訂單、商品、客人資料 | |
| 整合 | 把分散的工具接在一起 | |
| 同步 | 一邊改了，另一邊自動跟著改 | 「同步」老闆聽得懂，可保留 |
| Webhook | 一有新訂單就自動通知 | |
| 排程／Cron Job | 每天固定時間自動執行，例如每天早上 8 點寄報表 | |
| 自動化 | 讓系統自己做，不用人手動 | 「自動化」可保留，但要接具體的事 |
| 工作流程自動化 | 一個步驟做完，下一步自動接上 | |
| RPA | 讓電腦代替人做重複的點擊和複製貼上 | |
| n8n／Zapier／Make | 自動化工具（像幫各個軟體牽線的中間人） | 老闆不需要知道工具名，除非他要自己維護 |
| ETL／資料轉換 | 把資料整理成另一套系統看得懂的格式 | |
| 資料遷移 | 把舊系統的資料搬到新系統 | |
| 匯入／匯出 | 把資料放進去／拿出來（例如匯出成 Excel） | 可保留 |
| 第三方服務 | 別家公司的服務，例如綠界金流、LINE | 直接講服務名稱最清楚 |
| 金流串接 | 讓客人在網站上直接刷卡付款 | |
| 物流串接 | 下單後自動產生寄件單 | |
| 電子發票串接 | 結帳後自動開發票 | |
| LINE Bot／LINE 官方帳號串接 | LINE 上自動回覆、自動通知客人 | 「LINE」一定要留，老闆最熟 |
| Google Sheets 串接 | 資料自動寫進你的 Google 試算表 | |
| SSO／單一登入 | 一組帳號登入所有系統 | |

| 工程用語 | 老闆聽得懂的說法 | 可保留原詞的情況 |

| Wireframe／線框稿 | 畫面草圖 | |

| Sprint／敏捷開發 | 每兩週交一次進度給你看 | |

| 驗收 | 你確認沒問題 | 合約可保留 |
| 上線／Deploy／部署 | 正式上線、開始給客人用 | 「上線」可保留 |

| Hotfix | 緊急修正 | |
| 版本控制／Git | （不提） | |

| 交付 | 交給你 | |

| Scope／範圍 | 這次要做哪些、不做哪些 | |

## 10. 空泛詞黑名單

這些詞老闆聽了沒感覺，因為每家廠商都在用。**全部換成「具體解決什麼事」**。

| 空泛詞 | 為什麼不好 | 換成什麼 |
|---|---|---|
| 智慧（智慧系統、智慧客服） | 不知道聰明在哪 | 直接說它會做什麼：「客人問價錢，它會直接報價」 |
| 賦能 | 中國用語，台灣老闆陌生 | 「讓你的員工做得更快」 |
| 打造 | 動作很大，結果不明 | 「做」，或直接講成果 |
| 解決方案 | 沒說解決什麼 | 把問題講出來 |
| 一站式／全方位 | 每家都這樣說 | 列出真的包含的三件事 |
| 數位轉型 | 太大、太抽象 | 「把 Excel 換成系統」「訂單不用再手抄」 |
| 優化 | 不知道改善了什麼 | 「變快」「少出錯」「少花時間」 |
| 提升效率 | 抽象 | 「原本花 2 小時，現在 10 分鐘」 |
| 創新 | 自己說沒說服力 | 刪掉 |
| 領先／頂尖／專業 | 自己說沒說服力 | 用案例或數字證明 |
| 無縫接軌 | 工程話術 | 「資料自動同步，不用重打」 |
| 高效能 | 抽象 | 「網站 1 秒內打開」 |
| 場景 | 中國用語 | 「情況」「時候」 |
| 落地 | 工程圈口語 | 「真的用起來」 |
| 痛點 | 行銷圈用語（給老闆看時） | 直接講那個問題 |
| 抓手、閉環、顆粒度、對齊 | 中國網路用語 | 刪掉，用白話重寫 |
| 數據（指資料時） | 台灣用「資料」 | 「資料」；指數字時用「數字」 |
