# Iconify 圖示集

可以商用的 Iconify 圖示集，由 `scripts/sync_icon_sets.py` 從 Iconify 公開的圖示集清單產生，2026-10-31 同步，共 199 套。只收名稱、數量、授權與連結，不含圖示本身。

已用和 `search.py` 相同的白名單過濾：MIT、ISC、Apache-2.0、BSD-3-Clause、Unlicense、OFL-1.1、CC0、CC BY。GPL、MPL、CC BY-SA、CC BY-NC，以及停止維護的圖示集不在這裡。

格式：`**名稱** \`prefix\` — 中文說明 → 對應風格 id · 數量 · 授權 · 格線與樣式 · 變體 · 官方頁面`。prefix 用在 `search.py --prefixes`；變體用在 `--variant`（`base`＝沒有後綴的預設版）。官方頁面可以直接瀏覽整套圖示。
