# UX 模式與設計原則

## UX 模式 (UX Patterns)

- **漸進揭露 (Progressive Disclosure)** `prog` — 先給必要資訊，進階選項需要時才展開。
- **新手引導 (Onboarding / Coachmarks)** `onboard` — 第一次使用時用聚光燈或提示框導覽。
- **樂觀更新 (Optimistic UI)** `optim` — 先顯示操作成功，背景再同步，感覺更快。
- **遊戲化 (Gamification)** `gamify` — 用徽章、連續天數、進度條增加使用動機。
- **無限捲動 (Infinite Scroll)** `infinite` — 捲到底自動載入更多，取代分頁。
- **行動優先 (Mobile-first)** `mobilefirst` — 先設計手機版，再擴充到大螢幕。
- **社會認同 (Social Proof)** `social` — 顯示使用人數、評價與客戶標誌來建立信任。
- **復原取代確認 (Undo over Confirm)** `undo` — 直接執行，再給「復原」，取代「確定要刪除嗎？」的確認框。
- **個人化 (Personalization)** `personal` — 根據使用者行為調整內容與排序。
- **錯誤頁設計 (Error / 404 Page)** `e404` — 用插圖和幽默文案化解出錯的挫折感。
- **欺騙性設計 / 黑暗模式 (Dark Patterns)** `dark` — 誘導使用者的不當設計（隱藏取消、預設勾選）。注意：不是暗色主題（Dark Mode），列出來是為了避開。
- **AI 側邊助手 (Copilot Sidebar)** `copilot` — 在側邊欄常駐的 AI 對話面板。
- **提示建議 (Suggested Prompts)** `prompts` — 輸入框上方可以直接點的建議問題。
- **引用來源 (Citations)** `cite` — AI 回答裡附上的來源編號與連結。
- **鍵盤優先 (Keyboard-first)** `keyb` — 所有操作都能用快捷鍵完成。
- **拇指熱區 (Thumb Zone)** `thumb` — 把常用操作放在單手拇指搆得到的地方。
- **即時建議 (Autocomplete)** `autocomp` — 輸入時下方即時列出建議。
- **篩選面板 (Faceted Filters)** `facets` — 側邊多組勾選條件，用來縮小結果。
- **多步驟表單 (Wizard)** `wizard` — 把長表單拆成幾步，一步一步填。
- **自動儲存 (Autosave)** `autosave` — 不用按儲存，顯示「已儲存」狀態。
- **急迫感 (Urgency / Countdown)** `urgency` — 倒數計時或剩餘數量，要小心別變成暗黑模式設計。

## 設計原則 (Design Principles)

- **視覺層級 (Visual Hierarchy)** `hierarchy` — 用大小、顏色和位置排出閱讀順序。
- **格式塔原則 (Gestalt)** `gestalt` — 靠接近、相似、封閉讓人把元素看成一組。
- **8pt 網格 (8pt Grid)** `grid8` — 間距和尺寸都用 8 的倍數。
- **黃金比例 (Golden Ratio)** `golden` — 用 1:1.618 安排比例與構圖。
- **費茲定律 (Fitts's Law)** `fitts` — 按鈕越大、離游標越近，越容易點到。
- **希克定律 (Hick's Law)** `hicks` — 選項越多，做決定越慢。
- **米勒定律 (Miller's Law)** `miller` — 人一次大約只能記住 7±2 個項目。
- **雅各布定律 (Jakob's Law)** `jakob` — 使用者期待你的網站跟他常用的網站一樣運作。
- **美即好用效應 (Aesthetic-Usability Effect)** `aesthetic` — 好看的介面會被認為比較好用。
- **峰終定律 (Peak-End Rule)** `peakend` — 體驗的印象取決於最高點和結尾。
- **三分法 (Rule of Thirds)** `thirds` — 把重點放在畫面三等分的交點上。
- **垂直節奏 (Vertical Rhythm)** `vrhythm` — 行高與間距維持一致的節拍。
